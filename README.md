# 💻 ПК Мастер — Интернет-магазин электронной техники

## 1. 📋 Описание проекта
**ПК Мастер** — это полнофункциональный веб-сайт интернет-магазина электроники, созданный в рамках курсового проекта. Проект предназначен для продажи компьютерной техники и электроники, обеспечивая удобное взаимодействие как для покупателей, так и для сотрудников магазина.

**Целевая аудитория:**
*   Покупатели, желающие приобрести электронику онлайн.
*   Менеджеры магазина, обрабатывающие заказы и управляющие товарами.
*   Администраторы, контролирующие работу системы и пользователей.

## 2. ✨ Основные возможности
**Для гостей:**
*   Просмотр каталога товаров с фильтрацией по категориям.
*   Просмотр детальной страницы товара (описание, характеристики, цена).
*   Регистрация и вход в личный кабинет.

**Для покупателей:**
*   Все возможности гостя.
*   Добавление товаров в корзину и редактирование её содержимого.
*   Оформление заказа с указанием адреса и контактных данных.
*   Просмотр истории и статусов своих заказов.

**Для менеджеров:**
*   Добавление, редактирование и удаление товаров в каталоге.
*   Изменение статусов заказов (например, "В обработке", "Отправлен", "Доставлен").
*   Просмотр всех заказов в системе.

**Для администраторов:**
*   Все возможности менеджера.
*   Управление пользователями: блокировка, изменение ролей.

## 3. 🛠️ Стек технологий
*   **Бэкенд:** Python 3.12+, FastAPI
*   **База данных:** SQLite, SQLAlchemy (в качестве ORM)
*   **Аутентификация:** JWT (JSON Web Token)
*   **Шаблонизатор:** Jinja2
*   **Фронтенд:** HTML, CSS (без фреймворков)
*   **Контейнеризация:** Docker, Docker Compose
*   **Система контроля версий:** Git, GitHub

## 5. 🔐 Переменные окружения проекта
Для корректной работы приложения необходимо создать файл `.env` в корне проекта на основе `.env.example` или задать переменные окружения в системе.

| Переменная | Описание | Значение по умолчанию |
| :--- | :--- | :--- |
| `SECRET_KEY` | Секретный ключ для подписи JWT-токенов | `"секретный-ключ-по-умолчанию"` |
| `ALGORITHM` | Алгоритм кодирования JWT | `HS256` |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | Время жизни токена в минутах | `30` |
| `DATABASE_URL` | Строка подключения к базе данных | `sqlite:///./pc_master.db` |
| `FIRST_ADMIN_EMAIL` | Email для создания первого администратора | `admin@example.com` |
| `FIRST_ADMIN_PASSWORD` | Пароль для первого администратора | `adminchangeme` |
